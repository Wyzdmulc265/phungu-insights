About the Models

Minimum Variance (Markowitz): the portfolio with the lowest achievable volatility, from the inverted covariance matrix — historically robust on thin, correlated markets like the MSE. With auto-pick, selection is greedy: start from the least volatile stock, repeatedly add the one that most reduces total variance. Risk Parity: each stock contributes roughly equal risk (approximated by inverse volatility); auto-pick keeps the N least volatile stocks. Momentum / Value Tilts: weights scale with the Outlook page's technical and value z-scores; auto-pick keeps the top N by each score. Equal Weight has no view on which stocks are "best", so auto-pick ranks by risk-adjusted historical return (return ÷ volatility). The window selector changes the data feeding every estimate. Short windows track the current regime but are noisier; long windows (2Y / All) blend the 2024-25 rally, two share splits and the 2026 drawdown into one average that may describe no period in particular. Excluding a stock is not a recommendation to short it. This is an educational tool, not investment advice.
